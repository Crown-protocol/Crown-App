# crown-app — CLAUDE.md

Реп: **витрина, централизованный слой и подающий вписей**. Вне доверенного периметра: денег и ключей
эскроу не держит, книгу не считает, исход не решает.

Строгость, глоссарий, имена — канон `crown-spec/CLAUDE.md`. Архитектура — `crown-spec/docs/00-architecture.md`,
контракт игр — `games-harness.md`, место этого репа в проекте — `repo-map.md §Вне периметра`,
обязанности подающего — `07-build-plan.md §Контракт подающего впись`. Рабочий бриф репа —
`docs/ai-brief.md`, спека фронта — `docs/front.md`.

Специфика:

- **Копия замораживаемых констант — здесь, источник истины — у соседей.** `lib/chain/config.ts`
  повторяет id программ, минт, комиссию, флоры, тайминги и домены из `config/*.toml` периметра. Копия,
  которую никто не сверяет, уже разошлась, поэтому сверка — часть репа: `npm run verify:chain` читает
  соседние `.toml`/`.rs` и краснеет на расхождении, `npm run verify:games` — сообщения и прообразы
  областей против пиннутых векторов канистр. Меняя константу, меняй её у соседа, а сюда переноси.
- **Область — не адрес эскроу.** `task_id`/`collection_id` — свободные идентификаторы; адрес эскроу
  деривится от резолвера, резолвер — от области. Хранить адрес там, где канистра ждёт область (или
  наоборот) — молчаливая поломка: канистра ответит `NotFound`, деньги останутся в эскроу до дедлайна.
- **Порядок «рождение раньше регистрации» держит клиент.** Впись рождения (`/api/ingest`) и
  `push_root` (`/api/pushroot`) обязаны пройти до `register_task`/`create_collection`, иначе граница
  ответит `BadBirthProof` — и не скажет, почему. Тот же порядок спасает репутацию вкладчика: сеттлмент
  эскроу, чьего рождения индекс не видел, не сворачивается вовсе (`UnknownBirth`).
- **`lib/chain/roulette.ts` не имеет импортов, и это условие проверки, а не стиль.** У рулетки нет
  канистры: её трастлесс держится на том, что независимые реализации приходят к одному победителю,
  поэтому `verify:games` не грепает этот модуль, а **исполняет** его против векторов крейта
  (`crown-games/roulette/logic/tests/vectors.rs`). Bare Node может его загрузить только пока там нет
  ни `@/`-алиасов, ни web3.js, ни `Buffer` — только `Uint8Array` и `crypto.subtle`. Появится импорт —
  проверка станет SKIPPED, то есть исчезнет молча. `PublicKey` конвертирует вызывающий (`.toBytes()`).
- **Оплаченные вызовы — только на сервере.** Ingress не умеет прикреплять циклы; релей платит за ключ
  из своего allowlist. Ключ живёт в `RELAY_IDENTITY_JSON` (без `NEXT_PUBLIC_`) и в браузер не попадает
  никогда. Утёкший ключ капится per-key бюджетом релея — упереться в этот кэп значит авария.
- **За прямой донат платформа не платит** (`00 §9`). Подающий читает транзакцию и вписывает только то,
  в чём участвует фабрика: рождение эскроу и `claim`. Проверка идёт по чейну, не по полю запроса —
  подсказка вызывающего не является разрешением.
- **Потолок ретраев обязателен и живёт в БД** (`ingest_jobs`). Счётчик в памяти сбрасывается деплоем,
  то есть его нет; а без потолка нечитаемая транзакция ретраится вечно по `INGEST_PRICE` за попытку.
- **Витрина может отставать от книги, но не может её опережать.** Зеркальный индексер
  (`lib/server/indexer.ts`) читает `Settled` с чейна для фида — это удобство. Авторитет по репутации —
  канистра; выдавать зеркало за книгу нельзя.
- **Состав первого релиза — периметр + `conditional-tasks` + `conditional-funding`** (`07-build-plan §P8`).
  Аукцион и подписка в chain-режим не выводятся: `gamePrincipals.auction` всегда `false`, их UI живёт
  на синк-моке. Это решение, а не недоделка, — не «включай», не спросив.
- **Кнопки проверяются нажатием.** `npm run verify:ui` водит настоящий браузер (Playwright) по всем
  страницам без кошелька: жмёт каждый видимый контрол по одному на свежей загрузке и требует, чтобы
  он **что-то делал** (контрол, который ничего не меняет, хуже отсутствующего), чтобы у каждого была
  читаемая подпись, у каждого поля — подсказка, у выключенной кнопки — объяснение рядом, чтобы
  страница помещалась в 390px, работала с клавиатуры и не роняла ни одной ошибки в консоль. Плюс
  сквозные сценарии (донат до подтверждения и обратно, вкладки, поиск, каталог, оверлеи, 404) и обход
  всех внутренних ссылок. Страницы и виджеты берутся из `lib/data/games.ts` и `lib/data/overlays.ts`,
  поэтому новая игра или оверлей попадают под проверку сами. Гонять против `npm start`. Что он находил: обещание эскроу на игре без эскроу, семь копий-кнопок,
  молча ничего не делавших без clipboard API, дубль React-ключа в оверлее цели.
- **Игры за настоящие деньги в headless-браузере.** `node scripts/play-games.mjs [task|fundraiser|roulette|all]`
  подсовывает странице `window.solana` с настоящим ключом (`scripts/e2e-wallet.mjs`, подпись Ed25519
  через WebCrypto, никакого расширения) и проходит игру до денег: `verify:ui` ходит **без** кошелька и
  честно останавливается на подтверждении, а это — вторая половина вопроса. Формы округляют сумму до
  целых долларов, поэтому один прогон стоит $1 (протокольный флор devnet — $0.25); скрипт говорит это
  вслух, а не падает «Simulation failed» с пустым кошельком.
- **Эскроу-играм нужны канистры, и без них страницы честно уходят в превью.** Локально: `dfx start
  --clean --background`, деплой `crown-indexer` (без аргументов), затем `conditional-tasks` и
  `conditional-funding` с `(opt record { nns_root_key = <root_key реплики>; index = <principal индекса> })`,
  затем `crown-relay` с `games`/`index`/`allowlist` (принципал ключа из `RELAY_IDENTITY_JSON`), обеим
  играм — `bootstrap`, релею — циклы. Принципалы переносятся в `.env.local` (`NEXT_PUBLIC_*`) и
  **вшиваются в сборку**, поэтому после правки env нужен `npm run build`, а не просто рестарт.
  Проверка, что путь живой целиком: `POST /api/pushroot {"game":"task"}` → `RootPushed` (сервер →
  релей за циклы → канистра → сертификат индекса).
- **Локальный полный контур (все три игры за настоящие деньги).** Кроме реплики и четырёх канистр
  (выше) нужны ещё две вещи, обе найдены прогоном: **SOL RPC канистра** на пиннутом принципале
  `tghme-zyaaa-aaaar-qarca-cai` (релиз dfinity/sol-rpc-canister, `--specified-id`, `mode = Demo`,
  `overrideProvider` на `api.devnet.solana.com` и `updateApiKeys` с заглушкой — иначе индекс не
  прочитает devnet и `ingest` вечно `pending`), и `CHEER_SESSION_SECRET` в `.env.local` (без него
  прод-сервер не выдаёт сессию кабинета — 503, и раунд/сбор открыть некому).
- Проверки после изменений: `npx tsc --noEmit` (0 ошибок), `npm run verify:chain`, `npm run verify:games`,
  `npm run verify:db` и `npm run verify:ui` (последним двум нужен поднятый сервер). Один сервер,
  только `localhost:3000`.
